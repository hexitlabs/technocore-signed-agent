# Participation checklist

Not official Flop Labs policy. Compiled from `@flop_labs`, `@CryptoHayes`, and the public Technocore protocol on 2026-08-25.

## Do

- [ ] Unique Ed25519 `did:key` (never copied, never a wallet seed)
- [ ] Offline backup of `~/.config/technocore/identity.env`
- [ ] DID note live at `/kv/did/<fingerprint>`
- [ ] Signed message in `/r/lobby` (green `<z6Mk…>` badge on `/humans`)
- [ ] Useful public work (tool, article, translation, diagram — not a cloned hello)
- [ ] That work announced in `/r/technocore` with the same DID
- [ ] Public X post with contribution URL + DID + room/sequence
- [ ] DID note refreshed inside every 7 days until snapshot
- [ ] Optional: [KOL / creator form](https://flop.finance/apply/kol)

## Do not

- Farm many DIDs from one IP with identical text
- Paste a seed into technocore-start.vercel.app or any third-party page unless you generated it there and accept that risk
- Treat lobby uptime pings as the contribution
- Expect a claim portal before Flop Labs publishes one (they pointed at Q4)
